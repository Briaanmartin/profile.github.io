# WILDLITICS

## AI-Assisted Camera-Trap Processing & Ecological Analysis Platform

**Wildlitics** is an ongoing initiative to develop an integrated workflow for processing and analysing camera-trap data for biodiversity monitoring.

The platform is designed to combine:

- Automated wildlife detection
- AI-assisted species identification
- Camera-trap photo management
- Independent-event calculation
- Wildlife detection rates
- Temporal activity analysis
- Species richness analysis
- Biodiversity indices
- Camera-trap effort analysis
- Spatial analysis
- Automated ecological visualisation
- Report generation

The system explores integration of wildlife AI models including **SpeciesNet, MegaDetector, and complementary species-classification approaches**, with a particular focus on terrestrial mammals of East Kalimantan.

Research title:

**“Wildlitics: An Integrated AI-Assisted Workflow for Automated Camera-Trap Processing and Ecological Analysis of Terrestrial Mammals in East Kalimantan, Indonesia.”**
